Inside the model

distressCNN.keras is a Keras sequential convolutional neural network: two convolution/pooling blocks that pull features out of the image, followed by two dense layers that turn those features into a class prediction.

How an image becomes a prediction

  1. 1

    Input image

    Any JPG or PNG uploaded on the Classify page, in whatever size and color it was taken.

  2. 2

    Preprocessing

    Converted to grayscale and resized to 64×64, then pixel values are normalized to a 0-1 range.

  3. 3

    Model

    The 7-layer CNN below turns the 64×64×1 array into a score for each of the 13 trained classes.

  4. 4

    Output

    A softmax turns those scores into probabilities. The highest one is shown as the predicted distress type and severity.

Architecture

# Layer Output shape Params
1 Conv2D, 32 filters, 3×3, ReLU 62 × 62 × 32 320
2 MaxPooling2D, 2×2 31 × 31 × 32 0
3 Conv2D, 64 filters, 3×3, ReLU 29 × 29 × 64 18,496
4 MaxPooling2D, 2×2 14 × 14 × 64 0
5 Flatten 12,544 0
6 Dense, 128 units, ReLU 128 1,605,760
7 Dense, 13 units, Softmax 13 1,677
Total 1,626,253

1,626,253 trainable parameters, about 6.2MB as float32 weights. The saved distressCNN.keras file itself is larger (~18.6MB) because it also bundles the Adam optimizer's training state alongside the weights.
