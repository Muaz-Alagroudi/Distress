Inside the model

distressCNN.keras is a Keras sequential convolutional neural network: two convolution/pooling blocks that pull features out of the image, followed by two dense layers that turn those features into a class prediction.

Architecture

# Layer Output shape Params
1 Conv2D, 32 filters, 3×3, ReLU 62 × 62 × 32 320
2 MaxPooling2D, 2×2 31 × 31 × 32 0
3 Conv2D, 64 filters, 3×3, ReLU 29 × 29 × 64 18,496
4 MaxPooling2D, 2×2 14 × 14 × 64 0
5 Flatten 12,544 0
6 Dense, 128 units, ReLU 128 1,605,760
7 Dense, 13 units, Softmax 13 1,677

~1.63M trainable parameters, about 6.2MB.

Input & output

Input

A 64×64 grayscale image, pixel values normalized to a 0-1 range.

Preprocessing

The uploaded photo is converted to grayscale and resized to 64×64 before it reaches the model.

Output

A probability for each of the 13 trained distress/severity classes, the highest one is shown as the result.
